PHP is Fun

aaronwatts@dev 16 July 2026

Yeah sure PHP is dead and all that. I don't particularly care what the zeitgeist is, it's always changing and I'm here to enjoy myself first and foremost.

I've learnt a little PHP. Not much, just basic syntax and I haven't started looking at classes or OOP yet. But as a scripting language, and having used a lot of JavaScript and Python previously, it's not too difficult to pick up.

For my first practise project I decided to have a stab at making a new static site generator to replace the Python CMS module I was using to build my static site. PHP seemed a better fit for the task as it literally exists to create web pages.

So far it's going well. I expected to begin the project and find out that there's more that I need to learn to complete it. But with just the syntax and a procedural approach I am on my way and moving surprisingly quickly. The project is simple enough to work through without any OOP, at least for now. And the nature of PHP means there are far fewer steps involved with going from source data to full static site, especially when compared to my previous Python project. It should hopefully also simplify generating the XML files too, such as the RSS feed.

With not very much code at all I was able to ad lib a simple router that pushes files into templates, providing me with a live development environment to work in. And I intend to use CGI executions to write the built files into a static site directory. I've made some slight tweaks to how the source data is stored, which has made my posts much more portable. Although I don't feel like I want to make the switch to markdown just yet, unless someone provides a compelling argument to why I should. I'm open to it, if reluctant.

So far the project has been a treat, and I regret not having explored the world of PHP sooner. Once the project is complete, it's highly likely that I will export this very blog over to my main website, and just keep everything in one place. I will miss Publii's editor, but since they aren't likely to support ARM64 anytime soon then I might as well move on.
